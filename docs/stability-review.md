# 安定性レビュー（2026-09-16）

## 修正内容

- 保存先の読み書きで例外が発生しても起動・ゲーム進行を止めない。書き込み失敗時はセッション内の値を保持し、古い保存値に巻き戻さない。保存先が利用できない間の変更は、アプリ終了後の永続化を保証できない。
- 残高・最高スコア・進行度などの保存値に `NaN`、負数、小数、不正な文字列がある場合に初期値へ戻す。コイン増減にも数値検証を追加。
- ランキング認証の失敗を永久にキャッシュせず、次回の操作で再試行する。同時に進行中の認証要求は共有する。
- スコア送信内容を認証待ちの前に確定し、その間のステージ変更による取り違えを防ぐ。32ビット整数変換による高スコアの巻き戻りを除去。
- 古いランキング取得結果で新しい結果を上書きしない。名前の送信完了を待って再取得する。
- iOSの非アクティブ通知で音声だけでなくゲームループも停止する。復帰時にフレーム時計をリセット。
- 指操作のキャンセル、キャンバス外での指離し、画面切替、中断、サイズ変更でドラッグ状態を破棄する。別の指による操作の混入も防ぐ。
- コラボ画像の遅延読み込み完了時に、チュートリアル中のコラボ機能を有効化しない。
- 次のステージでBGMの再生要求を復元する。ブラウザーの効果音準備処理が、本再生を後から停止しない。
- 外部リンクを開いた後に、ゲーム自体を外部URLへ遷移させない。`noopener` は成功時にも `null` を返すため、戻り値だけで失敗と判定しない（[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/open)）。
- ログイン報酬は受け取り時にも日付を確認する。
- 低フレームレート時に時間を切り捨てず、最大50msずつに分割して更新する。長い停止の追いつきは250msまでに制限する。
- HUDの高さが変わったら盤面を再配置し、スコア表示・コラボゲージ・フォント読み込み後の重なりを防ぐ。上部セーフエリアも配置に含める。

## 検証

- `npm test`: 保存、ランキング、音声、フレーム制御、コラボなどの単体テスト。
- `npm run test:regressions`: Chromium / WebKit × 通常保存・保存不可・不正な保存値。起動、チュートリアル、入力中断、ネイティブ中断通知、ショップ、次ステージ、タイトル復帰を検証。
- `npm run test:mobile`: 320×568、390×664、390×844、844×390、1280×800を両エンジンで検証。横画面から縦画面への変更と、演出終了後のHUD・盤面の非重複も確認。
- `AUDIO_GAMEPLAY_TEST=1 MOBILE_TEST_BROWSER=webkit node scripts/check-mobile.mjs`: BGMのみ、効果音のみ、同時再生を検証。
- `npm run cap:sync`: Webを再ビルドし、iOS・Android用データへ同期。

Windows上のWebKitテストは実機のWKWebViewそのものではない。iOS署名ビルド、TestFlightでの出音・画面収録、実バックエンドへのランキング送信は今回の自動テストでは確認していない。

## ローカルビルド設定

`.env.local` がない状態では、ビルド後のランキング設定が空になっていた。既存の追跡済みiOS配布HTMLから公開接続設定を復元し、無視対象の `.env.local` に保存した。別の環境で再ビルドするときは `.env.example` を参考に `SUPABASE_URL` と `SUPABASE_PUBLISHABLE_KEY` を設定する。
