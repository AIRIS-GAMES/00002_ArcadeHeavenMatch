# おっ！サン コラボ素材

サンテレビ「おっ！サン」コラボ専用素材の配置先です。

## Rules

- サンテレビから提供または使用許諾を受けた素材だけを保存する
- 受領時の原本は編集せず、ゲーム用に加工した素材と区別する
- 素材ごとの加工可否、利用期間、権利表記を記録する
- 確認用ビルドを一般公開しない
- コラボ終了版の配布物には、このフォルダの素材を含めない

## Layout

- `source/`: 提供された原本（Git保存が許可された場合のみ）
- `characters/`: ゲーム用に書き出したキャラクター画像
- `ui/`: タイトル、ロゴ、背景など
- `review/`: 先方確認用資料（公開ビルドには含めない）
